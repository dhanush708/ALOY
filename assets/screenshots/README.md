# Screenshots

This directory contains screenshots of the ALOY user interface.

Screenshots will be added here following the v1.0.0 public release.

---

## Current Themes

ALOY ships with three UI themes:

- **Dark Theme** — Deep dark background, optimized for long sessions
- **Light Theme** — Clean white interface for high-ambient-light environments
- **OLED Theme** — Pure black (`#000000`), maximizing OLED screen battery savings

---

## Panels

The ALOY interface includes:

- **Conversation Panel** — Real-time streaming chat with Markdown rendering
- **Reasoning Console** — Live reasoning step output during multi-stage thinking
- **Agent Timeline** — Agent FSM state visualization and checkpoint history
- **Telemetry Sidebar** — Live CPU, RAM, GPU, and VRAM usage gauges
- **Settings Panel** — Model configuration, theme picker, memory management, database backups
- **Research Panel** — Web search, documentation explorer, workspace file browser

---

Screenshots will be provided in `PNG` format at `1920×1080` resolution.
