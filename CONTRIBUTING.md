# Contributing to ALOY

Thank you for your interest in ALOY!

ALOY is a proprietary application — the source code is not publicly available. However, you can still contribute meaningfully to the project in the following ways:

---

## How to Contribute

### 🐛 Report Bugs

Found something that doesn't work correctly?

1. Search [existing issues](https://github.com/dhanush708/aloy/issues) to see if it's already reported.
2. If not, open a new issue using the **Bug Report** template.
3. Include:
   - Your OS version (e.g., Windows 11 22H2)
   - ALOY version (shown in the About panel)
   - Ollama version (`ollama --version`)
   - GPU and VRAM (if applicable)
   - Clear steps to reproduce the issue
   - Screenshots if helpful

### 💡 Request Features

Have an idea for ALOY?

1. Search [existing issues](https://github.com/dhanush708/aloy/issues) to see if it's been suggested.
2. Open a new issue using the **Feature Request** template.
3. Describe the use case and why it would be valuable.

### ❓ Ask Questions

Stuck or confused?

1. Check [docs/faq.md](docs/faq.md) first.
2. Open a new issue using the **Question** template.

### 📢 Spread the Word

- ⭐ Star this repository
- Share ALOY with developers and AI enthusiasts
- Write about your experience
